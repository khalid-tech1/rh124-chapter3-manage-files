# Lessons Learned

## Key Concepts

During this project, I learned how to:

- Navigate the Linux file system using Bash.
- Work with both absolute and relative paths.
- Create and organize files and directories.
- Copy and move files efficiently.
- Remove files and directories safely.
- Use brace expansion to generate multiple filenames.
- Use wildcards to match multiple files.
- Create and verify hard links.
- Use command continuation with a backslash (`\`).

## Troubleshooting

While completing the lab, I learned how to identify and fix common command-line mistakes, including:

- Incorrect command options.
- Wrong file paths.
- Missing files or directories.
- Typing mistakes.
- File and directory removal errors.

## Reflection

Repeating the lab without looking at the solution helped reinforce my understanding of Linux file management. Instead of memorizing commands, I learned when and why to use them.
