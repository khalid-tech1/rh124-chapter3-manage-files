# Commands Practiced

## Basic Navigation

| Command | Purpose |
|---------|---------|
| `pwd` | Display the current working directory. |
| `ls` | List directory contents. |
| `ls -lR` | Display a recursive long listing of files and directories. |
| `cd` | Change the current directory. |
| `cd -` | Return to the previous directory. |

## File and Directory Management

| Command | Purpose |
|---------|---------|
| `mkdir` | Create directories. |
| `mkdir -p` | Create parent directories if needed. |
| `touch` | Create empty files. |
| `cp` | Copy files. |
| `mv` | Move or rename files. |
| `rm` | Remove files. |
| `rm -r` | Remove directories recursively. |
| `rmdir` | Remove empty directories. |
| `ln` | Create hard links. |

## Shell Features

| Feature | Example | Purpose |
|---------|---------|---------|
| Brace expansion | `{1..8}` | Generate sequences. |
| Brace expansion | `{1,2}` | Generate specific values. |
| Wildcard | `*` | Match multiple files. |
| Character match | `[56]` | Match selected characters. |
| Home directory | `~` | Shortcut to the home directory. |
| Parent directory | `..` | Refer to the parent directory. |
| Command continuation | `\` | Continue a command on the next line. |
